# SAT

Digital SAT prep materials, organized by subsection (no band levels).
Conventions: see `CLAUDE.md` in this folder. Shared quality rules:
`_Shared/CLAUDE-principles.md`.

| Subsection | Status |
|---|---|
| Reading and Writing | Mixed-domains practice (md), 550–650 practice + KEY |
| Math | Problem Solving module-1 practice at 550–650; Algebra & Advanced Math empty |
| Vocabulary | Top-100 flashcards, vocab-in-context 1200–1400, `sat-vocab-mastery-app` |
| Mock Tests | One modular mock at 550–650 + answer key |

Interactive apps: run `npm start` inside `Vocabulary/sat-vocab-mastery-app/`
(framework-free, offline-first).
